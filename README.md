👨‍💻 Personal Portfolio Website
A fully responsive and visually appealing personal portfolio website to showcase your projects, skills, and contact information. Built using HTML, CSS, and JavaScript, this portfolio is perfect for making a strong first impression.

🌟 Features
Clean and modern UI design

Responsive layout for all screen sizes

Sections for About, Skills, Projects, and Contact

Smooth scrolling and interactive elements

Easy to customize and extend

🛠️ Tech Stack
HTML5

CSS3

JavaScript

Clone the repository
git clone https://github.com/rhtmishra/Personal_Portfolio.git
